# Текстовая боёвка

## Описание

Консольная текстовая игра в стиле боёвки. Игрок сражается с врагами, использует предметы и зарабатывает опыт.

---

## Особенности проекта

- **ООП-структура**: Классы `Character`, `Player`, `Enemy`, `Goblin`, `Troll`, `Dragon`, `Item` с наследованием.
- **Игровой цикл**: Игрок по очереди сражается с различными врагами (вероятности появления настроены: гоблин, тролль, дракон).
- **Инвентарь/Предметы**: Использование предметов для лечения или усиления параметров.
- **Опыт и уровни**: Получение опыта, прокачка характеристик при повышениях уровня.
- **Сохранение и загрузка**: Прогресс игрока можно сохранить и потом загрузить (файл `save_game.json`).
- **Осмысленная структура кода**: Логичные деления на модули, состоящие из классов и функций (game.py, characters.py, items.py).

---

## Основной геймплей

1. **Старт**  
   Игрок выбирает: начать новую игру, загрузить сохранение или выйти.
2. **Бой**  
   После встречи с врагом игрок выбирает действие:
   - Атаковать  
   - Использовать предмет  
   - Посмотреть инвентарь  
   - Показать статус  
   - Сохранить игру  
   - Выйти  
   Если враг побежден — игрок получает опыт и может найти предмет.
3. **Новые враги**  
   После победы появляется новый противник (случайный выбор по заданным вероятностям).
4. **Цель игры**  
   Держаться как можно дольше — пока персонаж жив.
5. **Смерть**  
   При гибели выводится финальная статистика.

## Структура классов

- **Character** — базовый класс (здоровье, атака, защита; методы: `attack`, `take_damage`, `is_alive`, `describe`)
- **Player(Character)** — добавляет инвентарь, опыт, уровень, методы для работы с предметами и уровнем
- **Enemy(Character)** — базовый враг, за которого дают опыт; реализованы подклассы:
    - **Goblin** — слабый враг, появляется чаще всего
    - **Troll** — сильнее, появляется реже
    - **Dragon** — самый сильный, появляется редко
- **Item** — предмет (имя, тип эффекта, значение, метод `apply(target)`)
    - Примеры: Зелье лечения, Эликсир силы, Свиток защиты

## Файлы проекта

- `game.py` — главный игровой цикл, функции меню, сохранения/загрузки, генерация врагов и предметов
- `characters.py` — классы персонажей (Player, Enemy и наследники)
- `items.py` — класс и логика применения предметов
- `save_game.json` — автоматически создаётся для сохранения текущего состояния игрока
- `README.md` — данный файл с описанием структуры и правил работы с проектом

## Инструкция по запуску

1. Убедитесь, что установлен Python 3.
2. Скачайте файлы `game.py`, `characters.py`, `items.py` и т.д. в одну папку.
3. В командной строке/терминале перейдите в эту папку.
4. Запустите игру командой:

    ```python game.py```
    
5. Следуйте инструкциям в консоли.

## ООП-подход

- Каждая роль (игрок, враг, предмет) — отдельный класс
- Классы наследуют базовые свойства (Character), расширяют поведением
- Методы объектов описывают игровую логику боя, инвентаря, повышения уровня, применения предметов
- Взаимодействие персонажей и предметов происходит через вызовы методов и наследование
